# Web — Upwork Cover Letter AI SaaS

Next.js (App Router) frontend for PitchCraft.

## Local development

```bash
cd apps/web
npm install
npm run dev
```

Visit http://localhost:3000.

The design system follows `docs/design-handoff/` — dark base, Upwork green accent.

## Scripts

- `npm run dev` — Next.js dev server
- `npm run build` — production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript only check
